## Target for Nova Sitara
- Premium enterprise consulting aesthetic
- White/off-white canvas
- Black typography
- Nova Sitara purple #864EA8 as an accent
- Editorial layouts and generous whitespace
- Sophisticated 2D motion
- SVG line/path animation
- Typography reveals
- Subtle geometric movement
- Smooth section-to-section continuity

## Explicit restrictions
- No 3D
- No Three.js
- No React Three Fiber
- No WebGL
- No 3D models
- No heavy particle systems

Use React + TypeScript + CSS + SVG + GSAP/ScrollTrigger where useful.

## Motion principles
- Motion should be smooth, restrained and purposeful.
- Prefer opacity, transform, clip-path and SVG stroke-dashoffset.
- Avoid scroll-jacking.
- Do not animate every element.
- Preserve readability and usability.
- Respect prefers-reduced-motion.
- Mobile should use simplified motion.
